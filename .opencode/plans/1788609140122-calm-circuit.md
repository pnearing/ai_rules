## 3. Scoring & Budget Algorithm (`selection.py`)

**Query construction.** From `language`, `framework`, each mcp name, and `idea`: lowercase, split on non-alphanumerics, drop stopwords (constants.py list: python-irrelevant English glue words + over-generic hits like `test`, `project`, `code`, `use`, `using`), keep tokens len ≥ 3. Add a synonym expansion map (`py→python`, `ts→typescript`, `shell→bash`, `c#→csharp`, `k8s→kubernetes`…). Language tokens get weight multiplier 3, framework 3, mcps 2, idea 1.

**File-side tokens & score.** For each `RuleFile`, build a weighted token bag: basename tokens (weight 2), frontmatter `description` tokens (weight 3), `globs` tokens (weight 2), `headings` (weight 2), body content tokens (weight 1). Score = Σ over query tokens of (query_weight × max file-side weight where token appears). Additive boosts:
- `+10` if file category == language's category (via `LANGUAGE_CATEGORY_MAP` in constants).
- `+50` if file lives under `rules/mcp/<enabled-server>/` (enabled MCPs are *always* included, not merely boosted).
- `general/` files are not scored competitively — they are **always included first** (see order below).

**Inclusion order (deterministic).**
1. All `rules/general/*` files (core language-agnostic rules).
2. All `rules/mcp/<enabled>/*` files for each enabled MCP.
3. Remaining files sorted by `(−score, path)` — ties broken lexicographically by path so runs are reproducible.

**Token budget.**
- `CHARS_PER_TOKEN = 4` heuristic; `estimated_tokens(text) = ceil(len(text) / 4)`.
- Model context from Ollama (§4). Then: `excerpt_budget = resolve_budget(ctx)` = `int((ctx * 0.8) − RESERVED)` where `RESERVED = SYSTEM_PROMPT (~400 tok) + USER_SCAFFOLD (~800 tok) + OUTPUT_RESERVE (2048 tok)`. The 20% factor absorbs estimation error and chat-template overhead. `--budget N` overrides the computed excerpt budget outright (tokens).
- Per-file cap: a single file contributes at most `SINGLE_FILE_TOKEN_CAP = 1500` tokens; over-cap files are truncated at the cap with a `\n\n<!-- truncated: rules/x/y.md -->\n` marker (frontmatter `description` always kept — it's tiny and high-value).
- Walk the inclusion order, accumulate per-file token cost (content + citation line overhead), **stop/drop lowest-scoring first**: since order is by score, this is simply "take while it fits"; general/ and mcp/ files are admitted first regardless. Record dropped files in `SelectionResult.dropped`.
- Result: same corpus + same request ⇒ byte-identical selection (tested).

## 4. Ollama Integration (`ollama_client.py`)

> **Mandatory implementer step (Milestone 4 kickoff):** verify the *current* `ollama` Python package API via Context7 (`resolve-library-id` → ollama python library, then `query-docs` scoped to: `Client` constructor/host/timeouts; `list()` response shape for model names; `show(model)` response for context length; `chat()` signature, `messages` format, `options` dict incl. `num_ctx`/`temperature`; sync vs async). Signatures below are the *design intent*, adjusted to verified reality during M4.

- **Client construction:** `ollama.Client(host=host or env OLLAMA_HOST default http://127.0.0.1:11434, timeout=timeout_s)`. Sync client only (CLI; streaming not needed by default).
- **`list_models()`** → `client.list()`; extract model name strings; wrap connection failures as `OllamaUnreachableError` ("Is Ollama running? Start it with `ollama serve`."), map 404-ish model errors to `ModelNotFoundError`.
- **`context_window(model)`** → `client.show(model)`; read context length from the model info (field name verified in M4). If the model exposes none (older/registry models), fall back to `DEFAULT_CONTEXT = 4096` and emit a stderr warning. *Note:* server-side `num_ctx` defaults may be smaller than the model's trained window, so we pass `options={"num_ctx": min(model_ctx, computed_need)}` explicitly on generate.
- **`generate(...)`** → `client.chat(model=model, messages=[{"role":"system","content":system},{"role":"user","content":user}], options={"temperature": temperature, "num_ctx": num_ctx})`; return `response.message.content` stripped. **Non-streaming is the v1 default and recommendation**: the response is written atomically only after a complete, successful generation (simpler error semantics, no partial files); a `--stream` flag can be added later purely for UX. Temperature: `DEFAULT_TEMPERATURE = 0.2`.
- **Timeouts:** long generations are normal — default `timeout_s = 600.0`, overridable via `--timeout`. Connectivity pre-flight: a cheap `list_models()` call before generation so an unreachable server fails fast with exit code 4 rather than after prompt assembly.
- All calls go through the `OllamaClient` Protocol so tests inject `FakeOllamaClient` — zero `ollama` imports outside this module.

## 5. Wizard Flow (`wizard.py`)

Sequence (each step skipped when the corresponding flag was provided — flags act as pre-answers; no flags ⇒ full wizard):

1. **Language** — required. Prompt shows available categories from the loaded corpus as suggestions (`python, typescript, bash, csharp, kotlin, cpp, gamedev, ...`), free-text accepted; normalized via `LANGUAGE_CATEGORY_MAP`; empty/invalid ⇒ re-ask (max 3, then `MissingInputError`).
2. **Framework** — optional; empty accepted.
3. **Project idea** — from `--idea-file PATH` (UTF-8, must be non-empty; `PATH` of `-` reads stdin), else interactive multi-line: print instructions ("Describe your project idea. Finish with an empty line."), collect lines until a line that is empty after `strip()`; join with `\n`; require ≥ 1 non-blank line overall. Idea is **never** a single CLI argument.
4. **MCPs** — optional. Show detected servers (subdirectories of `rules/mcp/` minus `general`); comma-separated input; unknown names are kept but warned (no corpus section will match).
5. **Model** — required. `list_models()`; 0 models ⇒ `ModelNotFoundError` with hint (`ollama pull`); 1 model ⇒ auto-select with message; N ⇒ numbered menu, validated index.
6. **Output path** — default `./AGENTS.md` (shown; Enter accepts).
7. **Summary + confirm** — print language/framework/idea-preview/mcps/model/output/excerpt budget; `Proceed? [Y/n]`.

**Non-TTY behavior:** if a required input is missing and `sys.stdin.isatty()` is False ⇒ fail with `MissingInputError` and a message listing exactly which flags would have satisfied the wizard (CI-friendly). Piped stdin still works via `--idea-file -`. `Ctrl-C`/EOF during prompts ⇒ `WizardAbortedError` → clean exit (130), never a traceback.

**Default output path — `./AGENTS.md`, justified:** it is the tool's entire purpose (convention-location agents file), and it is *safe* because of the overwrite guard (§6): an existing file blocks the write unless `--force`, so the default cannot silently destroy anything. A timid default like `AGENTS.generated.md` would produce files agents don't read, undermining the tool.

## 6. Safety Mechanics

1. **Existing-file guard (`assert_writable`):** if target exists and not `force` ⇒ `OutputExistsError` (exit 1) telling the user to pass `--force` or `-o`. With `--force`: proceed. Writes are atomic (temp file in same dir + `os.replace`).
2. **Protected-path guard (dev-time safety, overrides `--force`):**
   - `find_package_repo_root()`: starting from `Path(agents_md_gen.__file__).resolve()`, walk ancestors looking for a directory containing **both** `pyproject.toml` (whose `[project] name == "agents-md-gen"`, parsed with `tomllib`) **and** `AGENTS.md`. That directory is the ai_rules repo root. Cache result.
   - `is_protected_path(target)`: `target.resolve()` (strict=False, resolves symlinks) `== (repo_root / "AGENTS.md")`. If protected ⇒ `ProtectedPathError` **regardless of `--force`**, exit code 3, message: "refusing to overwrite the ai_rules repository's own AGENTS.md — this repository is the tool's knowledge corpus".
   - If the tool is wheel-installed elsewhere (no marker found), protection is inert for end users — acceptable: this guard exists to protect *this repo during development*. Documented in module docstring.
   - Belt-and-braces: the agents-md writer also short-circuits on `is_protected_path` even if called directly, bypassing `cli`.
3. **Regression tests (test_safety.py):** (a) writer called with the *real* repo root `AGENTS.md` path and `force=True` ⇒ `ProtectedPathError`, file bytes unchanged (hash before/after); (b) `--force` CLI invocation targeted at repo root AGENTS.md ⇒ exit 3, file unchanged; (c) `--force` on a scratch tmp AGENTS.md ⇒ succeeds; (d) overwrite without `--force` ⇒ `OutputExistsError`; (e) symlink pointing at protected file ⇒ still refused (resolution check).

## 10. Risks & Open Questions

1. **ollama package API drift** — exact `list/show/chat` shapes and timeout plumbing must be confirmed via Context7 in M4; the wrapper Protocol contains the blast radius.
2. **Context-window detection gaps** — some models report no context length via `show`; fallback 4096 + warning; explicit `num_ctx` needed because server default may silently truncate the prompt.
3. **chars/4 heuristic error** — mitigated by the 20% margin + output reserve; a tokenizer-based estimator is a possible v2 refinement.
4. **Corpus curation debt** — several `other_rules` files are project-specific prompt noise (`save.md`, `if.md`, `website-fixes-plan.md`, `304-crypto-params.md`); they land in `general/` and may dilute prompts. A human curation/deletion pass is recommended post-M0 (user decision, not automatic).
5. **Idea keyword over-triggering** — generic idea words may over-select files; stopword list + min length for v1, IDF-style damping as future improvement.
6. **Nested `AGENTS.md` semantics** — solved by renames in §1.3; implementer must not "helpfully" restore those names.
7. **README update needs explicit user approval** (root docs stay untouched by default).
8. **Python 3.14 toolchain availability** on the dev machine — `requires-python >=3.14` is a hard requirement; verify interpreter exists in M1 before proceeding.
9. **v2 opencode.json writer** — schema not final; v1 ships the Protocol + stub only, no partial implementation.
10. **Windows/CJK edge cases** (path case-sensitivity, chars-per-token for non-Latin ideas) — acknowledged, out of scope for v1.
